About

I am a PhD student in the Database Systems group at TU Munich, advised by Prof. Jana Giceva. My research sits between database systems and cloud infrastructure. Cloud warehouses promise elasticity, but every design choice (how to provision, how to cache, when to scale) comes with a cost that is hard to reason about. I build models, simulators and benchmarks that make those trade-offs explicit, and then use them to argue for better system designs.

Lately I have also been looking below the database layer: how GPUs behave when their memory is oversubscribed, and what memory-centric hardware means for how we should architect data systems.

Research

One question underneath all of it: what does an analytical system actually pay for in the cloud, and how do we pay less?

  1. Cloud analytics architectures

    How should an analytical system be deployed in the cloud: elastic or static, warehouse or query-as-a-service, one region or many? CloudGlide is my simulator for answering that without deploying everything.

    CloudGlide PVLDB '25 CloudGlide demo SIGMOD '26 Autoscaling for cloud OLAP SESAME '24

  2. Metadata management & caching

    Disaggregated OLAP turns every cache into a distributed decision: what to keep, where, and whether sharing a cache across queries or tenants ever pays off.

    Ongoing student work, papers in progress.

  3. Modern hardware & efficient computing

    Below the database layer: GPUs, unified memory and memory-centric hardware, and what breaks when GPU memory is oversubscribed.

    Ember arXiv '26 Memory-centric database architectures Datenbank-Spektrum

  4. Serverless query processing

    Per-query billing turns query optimization into an explicit cost-performance trade-off. This started with multi-objective optimization in Spark SQL.

    From cloud to serverless EDBT '22 Multi-objective optimization in Spark SQL IDEAS '22

  5. Benchmarking

    TPC-H says little about real cloud workloads, and vendor telemetry strips the SQL. We argue for benchmarks built from concrete use cases such as ELT pipelines and BI dashboards.

    Cloud analytics benchmarking DBTest '26
