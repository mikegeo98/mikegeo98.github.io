About

I am a PhD student in the Database Systems group at TU Munich, advised by Prof. Jana Giceva. My research sits between database systems and cloud infrastructure. Cloud warehouses promise elasticity, but every design choice (how to provision, how to cache, when to scale) comes with a cost that is hard to reason about. I build models, simulators and benchmarks that make those trade-offs explicit, and then use them to argue for better system designs.

Lately I have also been looking below the database layer: how GPUs behave when their memory is oversubscribed, and what memory-centric hardware means for how we should architect data systems.

Research

Three threads, one question: what does an analytical system actually pay for in the cloud, and how do we pay less?

CloudGlide

PVLDB 2025 · SIGMOD 2026 demo

Cloud analytics architectures (warehouse-as-a-service, query-as-a-service, serverless) are compared by anecdote because nobody can afford to deploy all of them.

CloudGlide is a white-box simulation framework that pairs a queueing-theoretic model with a discrete-event simulator, so you can explore provisioning, scaling and caching decisions across architectures before spending a cent. The demo adds an interactive UI on top.

GPU memory under oversubscription

Preprint 2026

Unified Virtual Memory lets GPU workloads exceed device memory, but once they do, performance collapses by orders of magnitude.

We characterise where the time goes when a discrete GPU oversubscribes its memory and show how to make UVM usable in that regime, both in software and with hardware support for prefetching. Joint work with Dimitrios Stavrakakis and students from the group.

Benchmarking cloud analytics

DBTest @ SIGMOD 2026

TPC-H says little about the workloads cloud warehouses actually run, and the vendor telemetry that does is stripped of the SQL.

We take stock of what public cloud traces can and cannot tell us, argue that reconstructing queries from telemetry is a dead end, and propose building benchmarks from concrete use cases such as ELT pipelines and BI dashboards instead. With Till Steinert, Viktor Leis and Muhammad El-Hindi.
