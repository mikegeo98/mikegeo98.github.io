About

I am a PhD student in the Database Systems group at TU Munich, advised by Prof. Jana Giceva. My research sits between database systems and cloud infrastructure. Cloud warehouses promise elasticity, but every design choice (how to provision, how to handle metadata, when and how to scale) comes with a cost that is hard to reason about. I build models, simulators and benchmarks that make those trade-offs explicit, and then use them to argue for and implement better system designs.

Lately I have also been looking below the database layer: how GPUs behave when their memory is oversubscribed, and what memory-centric hardware means for how we should architect data systems.

Research

  1. Cloud database architectures

    How do we build database systems for the cloud that get the most out of object storage, run analytics cost-efficiently, and scale transactions across regions?

    CloudGlide PVLDB '25 CloudGlide demo SIGMOD '26 World Wide Wait ongoing

  2. Metadata management & caching

    Metadata can bridge the gap between cold and hot data access, but managing it at scale is a challenge of its own: what to maintain, and where to place it.

    Ongoing work.

  3. Modern hardware & efficient computing

    Enabling larger and more resource-efficient data processing on GPUs through unified memory, and our vision for how memory-centric hardware should be designed.

    Ember arXiv '26 · ongoing Memory-centric database architectures Datenbank-Spektrum

  4. Serverless query processing

    Serverless comes closest to the pay-as-you-go promise of the cloud and scales to very large data processing, but every unit of resource costs more. Query processing has to trade cost against latency explicitly.

    Multi-objective optimization in Spark SQL IDEAS '22

  5. Benchmarking

    TPC-H says little about real cloud workloads, and vendor telemetry is too noisy to rebuild workloads from. We argue for a clearer definition of transferable workload features, and for benchmarks built from concrete use cases.

    Cloud analytics benchmarking DBTest '26 · ongoing
